# firmware/ — 固件

4 个独立工程，对应硬件 4 类节点：

| 目录 | 节点 | 职责 |
| --- | --- | --- |
| `l103_joint/` | 每侧 1 颗 L103 | 3 路 KTH5502 采集（AB 计数 + SPI 绝对角） |
| `l103_hand/` | 每侧 1 颗 L103 | 摇杆、按键、Deadman |
| `h417_wearable/` | 穿戴主控 H417 | CAN 汇总、IMU、人体 FK、手部 XYZ、离合、nRF24 发送 |
| `h417_receiver/` | 接收机 H417 | RF 接收、坐标映射、双臂 IK、底盘、C620、安全 |

规则：

- 共用代码先在各自工程里跑通，再考虑抽公共目录，不要一上来搞 `common/`。
- 1 kHz 任务里不要 printf、不要动态内存、不要阻塞延时。
- 固件发布：编译好的 hex 不要提交仓库，打 tag 挂 Release 附件。
- 编译工具链（MounRiver）版本记在本目录 README 里，换版本要备注。
