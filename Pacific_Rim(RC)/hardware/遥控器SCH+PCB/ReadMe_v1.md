## 2. 穿戴端系统结构

```text
左侧关节区                         右侧关节区
KTH x 3 -> L103-JL               KTH x 3 -> L103-JR
                \                /
                 +----- CAN -----+
                 |               |
             L103-HL         L103-HR
             摇杆/按钮         摇杆/按钮
                 \               /
                  +---- CAN ----+
                         |
                      H417-W
              IMU / FK / XYZ / 离合
                         |
                      nRF24L01+
                         |
                    机器人接收机
```

关节角度主控板负责读取同一侧三个关节的 KTH5502。手部输入板负责摇杆和按钮。两套 L103 节点都通过 CAN 把最新状态发送给 H417-W。

## 3. 关节角度主控板

### 3.1 定位

该板是关节传感器采集节点，不是整台遥控器的 H417 中央主控。

每侧使用一块，负责：

- 三路 KTH5502 的 AB 正交计数。
- 必要时通过 SPI 读取绝对角。
- 角度零位、方向、速度估计和故障诊断。
- 通过 CAN 向 H417-W 汇报 `q1/q2/q3`。

### 3.2 主要 BOM

| 器件 | 型号/参数 | 封装 | 数量 | 用途 |
| --- | --- | --- | --- | --- |
| MCU | `CH32L103K8U6` | QFN-32 | 1 | 三路关节采集和 CAN 节点 |
| CAN 收发器 | `XL1057GT/3` | SOP-8 | 1 | CAN 物理层 |
| LDO | `ME6211A33M3G-N` | SOT-23 | 1 | 3.3 V 供电 |
| CAN ESD | `PESD2CAN-ES` | SOT-23 | 2 | CAN 总线保护 |
| 晶振 | 8 MHz | X3225 | 1 | MCU 外部时钟 |
| 传感器接口 | `HCZZ0323-8` | ZH1.5-8P | 3 | 三路 KTH 传感器 |
| 调试接口 | `HC-SH1.0-5PLT` | SH1.0-5P | 1 | SWD 调试 |
| CAN 接口 | `HCZZ0451-4` | PH2.0-4P | 2 | CAN 接入/级联 |

### 3.3 关键网络

原理图中可直接确认的网络包括：

```text
VCC
+3V3
GND
CAN-TX
CAN-RX
CANH
CANL
SWDIO
SWCLK
A1, B1, ADC1
A2, B2, ADC2
A3, B3, ADC3
```

三组传感器网络对应三路 KTH：

| 通道 | AB 正交信号 | 模拟/辅助信号 | 连接器 |
| --- | --- | --- | --- |
| 关节 1 | `A1`, `B1` | `ADC1` | `CN1` |
| 关节 2 | `A2`, `B2` | `ADC2` | `CN2` |
| 关节 3 | `A3`, `B3` | `ADC3` | `CN3` |

### 3.4 设计说明

- A/B 信号应接入 MCU 定时器编码器模式，不使用 GPIO 逐边沿中断计数。
- ADC 通道用于辅助检测和调试，不应替代 AB 运行时位置反馈。
- CANH/CANL 带独立 ESD 保护。
- 8 MHz 晶振用于 MCU 时钟。
- 3.3 V LDO 为 MCU 和数字接口供电。
- 板卡命名为“镜像”设计，左右侧安装时需确认连接器方向与线序。

### 3.5 固件边界

推荐固件职责：

```text
1 kHz:
  锁存三路编码器
  计算增量、方向和速度

低速/静止窗口:
  读取绝对角
  校验 CRC
  重建 AB 参考关系

250~500 Hz:
  发送 CAN q1/q2/q3/status/seq
```

禁止在 1 kHz 实时任务中频繁 `printf`、动态分配内存或阻塞等待 SPI。

## 4. 关节角度传感器板

### 4.1 定位

该板安装在人体关节附近，用于固定并连接一颗磁性角度传感器。

### 4.2 主要 BOM

| 器件 | 型号/参数 | 封装 | 数量 | 用途 |
| --- | --- | --- | --- | --- |
| 角度传感器 | `KTH5502LVPSP8-AB1024` | SOP-8 | 1 | AB 增量角/绝对角 |
| 接口 | `HCZZ0323-8` | ZH1.5-8P | 1 | 与角度主控板连接 |
| TVS | `SMF3.3A` | SMA | 1 | 输入保护 |
| 电感 | `1m` | L0603 | 1 | 电源滤波 |
| LED | 红色 0603 | 0603 | 2 | 电源/状态指示 |
| 电容 | 0.1 uF / 10 uF | 0603 | 3 | 去耦与储能 |

### 4.3 关键网络

原理图中可确认的网络包括：

```text
VCCIN
VCC
GND
A
B
ADC
PWM
```

其中：

- `A/B`：运行时正交增量输出。
- `ADC`：辅助模拟信号，具体用途以 KTH 数据手册和主控固件为准。
- `PWM`：传感器辅助数字输出之一，具体模式以实际配置为准。
- `VCCIN`：来自关节角度主控板的供电输入。
- `VCC`：传感器本地供电网络。

### 4.4 传感器模式

KTH5502 的基线约定：

```text
MODE = 0 -> AB 正交输出
MODE = 1 -> 数字接口，SPI 三线或 I2C
AB1024 -> 四倍频后约 4096 counts/rev
数字角 -> 16 bit
SPI -> 三线，Mode 3，最高 5 MHz
```

第一版建议：

1. 上电等待传感器初始化完成。
2. 以 AB1024 作为连续运行反馈。
3. 使用 SPI 绝对角进行初始化、校准和故障恢复。
4. 不依赖运行中动态切换 MODE。

### 4.5 机械和磁场注意事项

KTH5502 的读数直接受磁铁影响。修改以下结构后必须重新标定：

- 磁铁与芯片的轴向距离。
- 磁铁中心与芯片中心的偏差。
- 磁铁材质、尺寸和充磁方向。
- 传感器板安装角度。
- 线束和金属件附近的磁场干扰。

结构件与传感器板不能只按外形装配，应同时记录机械零位和角度正方向。

## 5. JLCEDA 打开方式

这两个目录中的 JSON 不能直接当普通文本修改。

推荐流程：

1. 打开嘉立创 EDA。
2. 选择打开本地/离线工程。
3. 导入对应目录的顶层 JSON：
   - `环太平洋-关节角度主控/环太平洋-关节角度主控.json`
   - `环太平洋-关节角度传感器/环太平洋-关节角度传感器.json`
4. PCB 工程位于同名目录下的 `PCB_*.json`。
5. 修改后同时保存原理图、PCB 和 `info` 文件，避免版本不一致。

不要只复制 `PCB_*.json` 到新目录，因为它依赖顶层工程元数据和 UUID。

## 6. 上电和调试顺序

### 6.1 关节角度主控板

1. 只接 3.3 V 电源，检查电压和电流。
2. 连接 SWD，确认芯片可识别。
3. 下载最小点灯/串口程序。
4. 检查 8 MHz 晶振。
5. 分别连接一块传感器板。
6. 验证 A1/B1、A2/B2、A3/B3 的计数方向。
7. 验证 CANH/CANL 波形和终端电阻。
8. 同时连接三路传感器进行长时间测试。

### 6.2 关节角度传感器板

1. 检查 `VCCIN` 和 `VCC`。
2. 确认 LED 状态。
3. 用示波器观察 A/B 输出。
4. 缓慢旋转磁铁，检查计数连续性和方向。
5. 跨越 0°/360° 连续旋转，检查是否丢计数。
6. 验证 ADC/PWM 网络。
7. 记录磁铁安装位置和角度零点。

## 7. 标定内容

每颗 KTH 至少需要保存：

| 参数 | 说明 |
| --- | --- |
| `counts_per_rev` | AB1024 四倍频后通常为 4096 |
| `angle_zero` | 对应关节的安装零位 |
| `direction` | `+1` 或 `-1` |
| `magnet_center_offset` | 磁铁中心偏差 |
| `magnet_air_gap` | 磁铁与芯片间距 |
| `min/max_limit` | 关节机械限位 |
| `speed_filter` | 速度滤波参数 |

参数建议保存在 L103 参数区，并由 H417-W 统一管理版本。

## 8. CAN 节点建议

| 节点 | CAN ID | 内容 |
| --- | --- | --- |
| 左侧关节节点 | `0x101` | `q1/q2/q3/status/seq` |
| 右侧关节节点 | `0x102` | `q4/q5/q6/status/seq` |
| 左手输入节点 | `0x111` | 摇杆/按钮/status/seq |
| 右手输入节点 | `0x112` | 摇杆/按钮/status/seq |
| H417 状态 | `0x120` | 模式、链路、传感器、故障 |
| H417 同步 | `0x121` | 时间戳/同步标记 |

所有控制数据必须带序号或时间戳，H417-W 应丢弃旧帧并检测节点失联。

## 10. 验收清单

- [ ] 左右镜像板的连接器方向一致且不会误插。
- [ ] 三路 A/B 计数方向与关节正方向一致。
- [ ] 三路传感器可同时工作。
- [ ] 0°/360° 跨点连续运动不丢计数。
- [ ] SPI 绝对角 CRC 正常。
- [ ] CAN 在机械臂运动噪声下无异常错误帧。
